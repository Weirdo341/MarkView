# MarkView

简洁的本地 Markdown 阅读与编辑工具（Windows 桌面应用）。双击 `.md` 即可安静阅读：大纲导航、三套主题、代码高亮、数学公式与 Mermaid 图表；阅读视图像 txt 一样直接编辑、实时自动保存；一键导出 PDF 与整篇长图。完全离线，不上传任何内容。

当前版本：**v1.1.0 (Date 20261117)**

## 1. 安装与启动

**下载安装包**（GitHub Releases）：

- 安装版：[MarkView-Setup-1.1.0-20261117.exe](https://github.com/Weirdo341/MarkView/releases/download/v1.1.0-20261117/MarkView-Setup-1.1.0-20261117.exe)
- 便携版：[MarkView-Portable-1.1.0-20261117.exe](https://github.com/Weirdo341/MarkView/releases/download/v1.1.0-20261117/MarkView-Portable-1.1.0-20261117.exe)

**安装版**：双击 `MarkView-Setup-1.1.0-20261117.exe`，按向导选择安装目录（可创建桌面快捷方式）。安装后在开始菜单或桌面启动 MarkView。

**便携版**：双击 `MarkView-Portable-1.1.0-20261117.exe` 直接运行，无需安装，可放在 U 盘随身携带。

**源码运行**（开发者）：需要 Node.js 18+。

```bash
npm install        # 安装依赖
npm start          # 构建渲染层并启动
npm run dev        # 监听模式构建（另开终端 npm start 启动）
node scripts/make-icon.mjs   # 生成应用图标（首次打包前执行）
npm run dist       # 打包安装版与便携版（产物在 package/）
```

## 2. 打开文件

- **双击关联**：设置默认应用后（见第 6 节），双击 `.md` / `.markdown` / `.txt` 直接用 MarkView 打开；右键菜单也有「用 MarkView 打开」。
- **拖拽**：把 Markdown 文件拖入窗口任意位置。
- **Ctrl+O** 或工具栏「打开」按钮选择文件；欢迎页保留最近打开列表。
- **文件树**：侧栏切换到「文件」页签，浏览当前文件所在目录（目录懒加载展开），点击即切换文档。
- 欢迎页提供「查看示例文档」，一份覆盖全部格式的演示文件。

## 3. 阅读体验

- **主题**：浅色 / 深色 / 护眼三套，工具栏按钮循环切换，或在「视图」菜单指定。
- **字体与排版**：「视图 → 字体与排版…」可调正文字号（14–24px）、行高（1.4–2.4）、段距，实时生效并记住；「视图」菜单可切换黑体 / 衬线。
- **大纲**：侧栏「大纲」页签随滚动高亮当前章节，点击跳转；与编辑区滚动同步。
- **缩放**：`Ctrl+=` / `Ctrl+-` / `Ctrl+0`，或按住 Ctrl 滚轮；状态栏显示比例。
- **专注写作**：`F8` 聚焦模式（非当前段落淡出）、`F9` 打字机模式（光标段落保持屏幕居中）；「视图」菜单另有宽屏视图与全屏（F11）。
- **查找替换**：`Ctrl+F` 打开双行查找条；阅读视图全文高亮所有匹配并显示 `当前/总数`，`Enter` / `Shift+Enter` 跳转，`Aa` 区分大小写；第二行输入替换内容后「替换」或「全部替换」，`Ctrl+Z` 可整体撤销。打开查找时会自动带入当前选中的文字。
- **渲染能力**：代码块语法高亮（带语言标签与复制按钮）、KaTeX 数学公式（行内 `$…$` 与块级 `$$…$$`）、Mermaid 流程图 / 时序图 / 饼图、脚注、任务列表、表格对齐；扩展语法 `==高亮==`、`^上标^`、`~下标~`，以及单独一行的 `[toc]` 段内目录。
- **图片**：单击打开灯箱，滚轮缩放、拖拽平移、`1:1` 复位；双击图片同效。单击正文图片还可配置替代文字与路径。
- **表格**：悬停出现「配置」按钮，可设列宽 / 对齐 / 行高；拖拽表格边缘直接调列宽行高；右键单元格可在上 / 下插入行、左 / 右插入列、删除行列。

## 4. 编辑与保存

- **阅读视图直接编辑**：整篇文档即编辑区，单击定位光标即可输入，回车换行所见即所得；停止输入约 0.25 秒后自动保存（状态栏显示保存时间），无需手动保存，`Ctrl+S` 亦可立即保存。
- **浮动工具栏**：选中文字后浮出 `B I S 代码 | 七色色块 A | 链接 清除格式`。色块一点即着色；`A` 打开完整色板（主题色 / 标准色色块、`#hex` 自定义输入、屏幕取色笔、清除颜色）；再次点击已生效的格式按钮可取消该格式。
- **插入菜单**：标题一至六级、加粗 / 斜体 / 删除线 / 高亮 / 上标 / 下标 / 行内代码 / 代码块、文字颜色、链接、图片、表格、列表 / 任务列表 / 引用 / 分隔线、数学公式 / 行内公式 / 脚注、三种 Mermaid 模板。阅读视图选中文字后执行高亮 / 上标 / 下标为原位切换（再执行一次取消）。
- **链接**：单击链接弹出编辑框（名称 + 地址两行，带合法性校验），可打开 / 移除 / 应用；`Ctrl+单击` 直接打开链接；选中文字点浮动栏链接按钮即插入新链接；选中文字时粘贴 URL 自动套成链接。
- **粘贴与拖拽图片**：编辑时 `Ctrl+V` 粘贴剪贴板图片，自动存到文档旁 `assets/pasted-*.png` 并插入引用；把图片文件拖入正文则在光标处插入相对路径引用（拖 Markdown 文件仍为打开）。
- **复制为**：编辑菜单「复制为 Markdown / 复制为 HTML」，把选区按源码或渲染后 HTML 复制出去。
- **块操作**：悬停段落 / 表格 / 代码块右上角出现「删除」整块按钮；拖拽块可调整顺序；`Ctrl+Z` 撤销、`Ctrl+Y` 重做（阅读与源码模式通用）。
- **源码模式**：`Ctrl+E` 切换左右分栏（左源码右预览，滚动同步），适合精确调整 Markdown 语法；再按 `Ctrl+E` 回到阅读视图。

## 5. 导出与分享

- **PDF**：`Ctrl+P` 或「文件 → 导出 PDF」。A4 排版、页脚页码、强制浅色纸面风格；加粗使用真实粗体字形，清晰不糊。
- **长图**：`Ctrl+Shift+E` 或「文件 → 导出长图」，整篇文档渲染为一张 PNG（超过 16000px 高度会截断并提示）。
- **HTML**：`Ctrl+Shift+H` 或「文件 → 导出 HTML」，单文件内联样式与公式字体，离线可打开、可直接发邮件或贴进网页。
- 导出自动忽略聚焦淡出、搜索高亮、浮动工具栏与弹窗等临时界面状态，产物始终是干净的文档。

## 6. 文件关联与卸载

**注册关联**（仅当前用户，无需管理员）：

```bash
node scripts/associate.mjs
```

写入 HKCU 注册表：`.md` 等扩展名的打开方式候选、右键「用 MarkView 打开」动词、应用列表登记。

**设为默认**：Windows 设置 → 应用 → 默认应用 → 按文件类型选择默认应用 → 找到 `.md` → 选择 MarkView；或右键 `.md` → 打开方式 → 选择其他应用 → 勾选「始终使用此应用」。Windows 保护用户默认选择，脚本不会静默篡改。

**解除关联**：

```bash
node scripts/unassociate.mjs
```

**卸载**：安装版在 Windows 设置 → 应用 → 安装的应用中卸载 MarkView；便携版直接删除 exe 即可。卸载不会删除你的 Markdown 文件。

## 7. 常见问题

- **PDF 里加粗发虚？** 已使用真实粗体字体嵌入修复。个别 Mermaid 图表符号仍可能位图化，属图表渲染特性，不影响正文。
- **提示「文件被外部修改」？** 自动保存的回声已被抑制，正常编辑不会误报；确有其他程序改动文件时会自动刷新并保留阅读位置。
- **阅读视图点了没反应 / 不能输入？** 单击正文任意处即进入编辑；若刚切换窗口，再点一次即可。整块删除等操作用 `Ctrl+Z` 找回。
- **公式 / 图表需要联网吗？** 不需要，KaTeX 与 Mermaid 均内置离线渲染。
- **粘贴的图片存在哪？** 文档所在目录的 `assets/` 下，文件名 `pasted-时间戳.png`，随文档一起拷贝即可保持引用。
- **杀毒软件报毒？** 安装包未做商业签名，属本地开源工具误报，添加信任即可；源码可自行审计与构建。
- **配置存在哪？** `%APPDATA%/markview/config.json`（主题、字号、最近文件、窗口位置等），删除即恢复默认。
- **如何检查更新？** 帮助 → 检查更新…：对比 GitHub 最新 Release（仅此刻联网一次）；有新版弹窗提供「下载更新」跳转 Release 页，已最新或网络失败仅提示，不会自动下载或安装。
- **功能边界在哪？** 有意不做：Word / pandoc 导出（需外部依赖）、多窗口标签页、图床上传、自定义 CSS 主题、拼写检查；正文内联 HTML 出于安全考虑不渲染（`html:false`）。其余阅读 / 编辑 / 导出能力见上文。
